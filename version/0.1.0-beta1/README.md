# Ice And Fire: Bond Beyond 🐉🌊

Ice And Fire: Bond Beyond is an unofficial addon for [Ice and Fire: Dragons](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons), focused on expanding selected creatures with deeper companion mechanics.

Instead of only fighting or hunting them, Bond Beyond aims to let players hatch, raise, tame, breed, equip, ride, and care for them.

> This repository contains the source for the early Beta 0.1.0 release. The current release focuses on Sea Serpents.

## 🌊 Beta 0.1.0

Current Sea Serpent features include:

- Sea Serpent Eggs with multiple color variants
- Egg hatching
- Player ownership and taming
- Growth mechanics
- Breeding
- Sea Serpent Saddles
- Sea Serpent Armor
- Rideable tamed Sea Serpents
- Expanded riding, swimming, and companion interactions

Hydras, Stymphalian Birds, Myrmex, and other creatures are planned for later development and are not part of the current 0.1.0 feature set.

## 🔧 Development Environment

- Minecraft 1.20.1
- Forge
- Java 17
- Gradle Wrapper included

The project depends on Ice and Fire: Dragons and Citadel. The current development configuration also includes Tectonic for the deeper-ocean environment used by Sea Serpent egg pressure mechanics.

## 🛠️ Building

Clone the repository, make sure Java 17 is available, then run:

Windows:

```powershell
.\gradlew.bat build
```

Linux/macOS:

```bash
./gradlew build
```

The built mod JAR will be generated under `build/libs/`.

For a development client:

```powershell
.\gradlew.bat runClient
```

## ❤️ What Bond Beyond Changes

The original Ice and Fire mod primarily presents Sea Serpents as dangerous hostile ocean creatures. Bond Beyond keeps Ice and Fire as the required foundation and adds a companion-focused progression around those creatures, including eggs, hatching, ownership, growth, breeding, equipment, and riding.

Bond Beyond is not an official Ice and Fire update, replacement, or continuation, and it does not function without the original mod.
