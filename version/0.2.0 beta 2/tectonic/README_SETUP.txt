Windows:
1. Install JDK 17.
2. Open this folder in IntelliJ IDEA.
3. Open Terminal here.
4. Run:
      gradlew.bat genIntellijRuns
5. Then test:
      gradlew.bat runClient
6. Build jar:
      gradlew.bat build
   Output:
      build/libs/
